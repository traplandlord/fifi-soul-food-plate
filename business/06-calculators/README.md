# What-if calculators

Interactive tools (vanilla HTML/JS) for investors and operators:

- **A — Profit by plate × platform** (Pickup, LIVE, DoorDash, Grubhub, Overnight, Local delivery) with editable itemized COGS
- **B — Day/week what-if** with **24hr full-throttle** and mode toggle: **Pop-up only** vs **With location**
- **C — Side-by-side** pop-up vs location at the same volume

**Live page (site):** `/business/calculators.html` on the ordering site / GitHub Pages.

Defaults come from `calculator-config.js` (mid knobs from COGS + flywheel sim).

Illustrative · Not financial advice.
